# Terraform AWS EC2 Project

## 📌 Overview
This project provisions an EC2 instance on AWS using Terraform.

## ⚙️ Tools Used
- Terraform
- AWS EC2

## 📂 Files
- main.tf → Terraform configuration

## 🚀 How to Run
1. Install Terraform  
2. Configure AWS CLI  
3. Run:
   terraform init  
   terraform apply  

## 💡 What This Project Shows
- Infrastructure as Code  
- AWS provisioning  
- Terraform basics
